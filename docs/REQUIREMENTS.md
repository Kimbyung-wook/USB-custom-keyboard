# 요구사항

- 지금까지 정한 요구사항을 식별자로 모은 문서. 다른 문서는 이 식별자(`REQ-…`)로 가리킴
- 사용법은 [MANUAL.md](MANUAL.md), 보드별 값은 [BOARDS.md](BOARDS.md), 설계·구현은 각 문서

## 규칙

- 식별자: `REQ-<분야>-<번호>`. 번호는 한 번 붙이면 바꾸지 않음. 없앤 요구사항은 지우지 않고 상태를 "폐기"로
- 분야: BOARD(보드·하드웨어), KEY(입력), LOCK(잠금·패턴), LED, BLE(무선·동글), BOOT(부트로더·장입), CFG(설정·저장), GUI
- 상태
  - **구현 중**: 정했고 코드를 만드는 중
  - **구현됨**: 코드·PC 시험 있음, 기판 확인 전
  - **기판 확인됨**: 실제 보드에서 확인
    - 묶음(전체·RGB 등) 중 아직 기판에서 안 본 보드는 "· SAYO_2X6 확인 전"처럼 뒤에 붙임
  - **보드 확인 실패**: 실제 보드에서 안 됨. 원인 조사 중
  - **미구현**: 정했지만 코드 없음
  - **결정 대기**: 충돌하거나 정하지 않음. 지금 동작은 그대로 두고 사용자 결정을 기다림
- 보드 묶음: 전체 = 지원 보드 6개, CH552 = MK6K1N·MK6K1NL, RGB = SAYO_3X3·SAYO_2X4·SAYO_2X6, 2B3 = SAYO_2B3, 동글 = SAYO_2B3 동글(CH582F), 노브 없음 = RGB + 2B3
- 결정일은 처음 정한 날. 바뀐 내용은 출처 문서의 이력과 이 문서 "이력"
- 옛 번호: README 핵심 요구사항 표의 #1~#4 = REQ-BOARD-01, REQ-KEY-01, REQ-KEY-03, REQ-LOCK-01
