# 보드 문서 양식 (`docs/board/BOARD_<보드>.md`)

- 모든 보드 문서는 아래 절 순서·제목·표 열 이름을 그대로 씀. 해당 없는 절은 "해당 없음" 한 줄
- 본문은 현재 상태만. 날짜·버전별 변경은 **각 절 끝 `**이력**`**에 짧게(따로 "이력" 절을 두지 않음)
- 다른 보드와 같은 내용은 옮겨 쓰지 않고 링크(예: MK6K1NL → MK6K1N 노브 신호)
- 예: [BOARD_3X3V_RGB.md](BOARD_3X3V_RGB.md)

## 절 순서

```markdown
# <보드> 보드 (<키 수>키[ + 노브], <LED 방식>)

- 요약 표: [BOARDS.md](../BOARDS.md). (같은 계열 보드 링크)

## 1. 개요
- 제품, 칩(패키지, 플래시/RAM, 부트로더), 구성(키·노브·LED), 개발 보드 UID, 확인 근거(시험 펌웨어 README, 날짜)

## 2. 버튼 배치와 매핑
![<보드> 버튼 별 맵핑: ...](../images/buttons_<보드>.svg)
<!-- gen:pins-<보드> -->
(tools/gen_docs.py가 채움)
<!-- /gen:pins-<보드> -->
- 생성 표에 없는 것: 슬롯, 칩 핀 번호, 음극 묶음의 키, 펌웨어 핀 이름, 특수 핀(SWD 등), 번호 매기는 순서

## 3. 칩 핀맵
![<보드> 칩 핀맵: ...](../images/pinmap_<보드>.svg)
| 핀 번호 | 이름 | 용도 | 비고 |
- 핀 번호가 확실하지 않으면 "확인 필요"로 표시(추측한 번호를 확정처럼 쓰지 않음)

## 4. LED
- 방식(WS2812 체인 / 음극 묶음 × 키별 양극), 극성, 색 순서, 밝기, 꽂을 때 점검. 핀 표

## 5. 부팅·장입
- 진입 키, 처음 설치(공장 펌웨어), 평소 업데이트, 주의(읽기 보호 등)

## 6. 본 펌웨어에서의 동작
- 보드 파일, 빌드 명령과 산출물, 슬롯, 잠금, 다른 보드와 다른 점

## 7. 확인 결과
| 항목 | 상태 |

## 부록 (선택)
- 참고 키보드로 확인할 것 등
```

## 표 열

| 표 | 열 |
|---|---|
| 버튼 매핑 (2절) | 생성 구역 `pins-<보드>` (손으로 쓰지 않음). 열은 `tools/gen_docs.py`가 정함 |
| 칩 핀맵 (3절) | 핀 번호 \| 이름 \| 용도 \| 비고 |
| LED 핀 (4절) | WS2812: 순서 \| 키 \| 비고. 음극 묶음: 묶음 \| 키 \| 빨강 \| 초록 \| 파랑 |
| 확인 결과 (7절) | 항목 \| 상태 |

- 생성 구역(`gen:이름` 표시와 `/gen:이름` 표시 사이, HTML 주석) 안은 손으로 고치지 않음. 표시만 손으로 넣고 `uv run python tools\gen_docs.py`로 채움, `--check`로 검사
- 새 보드: `gui/core/boards.py`·보드 파일에 추가하면 `pins-<보드>` 구역을 쓸 수 있음
- 칩 핀맵 표: 쓰는 핀은 한 행씩. 전원·GND·안 쓰는 핀은 묶어서 한 행

## 그림 만들기

- 모든 보드 문서의 그림은 스크립트로 그림(`docs/images/`)

| 그림 | 보드 | 스크립트의 값 |
|---|---|---|
| `buttons_<보드>.svg` 버튼 별 맵핑 | 모든 보드 | CH552: `PINS`(칩 핀), `KEY_PINS`(키 → 칩 핀). CH32V203: `RGB_BOARDS` |
| `pinmap_<보드>.svg` 칩 핀맵 | 모든 보드 | CH552: `PINS`. CH32V203: `CH32_PINS`(48핀 이름) + `RGB_BOARDS` |
| `pinmap_ch552g.svg` CH552G 공통 핀맵 | MK6K1N·MK6K1NL | `PINS` |
| `leds_<보드>.svg` LED 배선 | CH32V203 보드 | `RGB_BOARDS`(키 핀, 양극, 음극 묶음, 진입 키) |

- 값의 근거는 `firmware/macro_keyboard/src/boards/<보드>.h`. 핀이나 연결이 바뀌면 스크립트 값을 고치고 다시 그림
- 새 보드: 같은 칩이면 표에 보드 값만 추가. 새 칩이면 칩 그림 함수도 추가

```powershell
uv run python tools\draw_pinmap.py
```
