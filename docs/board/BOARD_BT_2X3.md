# BT_2X3 보드 (6키, 블루투스, 식별 중)

- 요약 표: [BOARDS.md](../BOARDS.md#준비-중-보드). 문서 양식: [_TEMPLATE.md](_TEMPLATE.md)
- **상태: 식별 중** (기판 모델명·칩 표기 확인, 자료표·USB·동글 확인 전). 이름 `BT_2X3`은 임시(식별 뒤 바꿀 수 있음, 아직 안 바꿈). 파일 위치·블루투스 주의: [NEW_BOARD.md 9절](../NEW_BOARD.md#9-식별-전-보드)

## 1. 개요

- 제품: 제조사 미상 6키 블루투스 매크로 키보드 (제품명 확인 필요)
- 기판 모델명(실크): `2x3M_BLE_Ver1.1` (사용자 관찰, 2026-11-13)
- 칩: WCH **CH573F** (칩 표기 (사용자 관찰, 2026-11-13)). 표기의 `1042FF04`는 로트 번호로 보임. 특성: [CHIPS.md](../CHIPS.md#칩-특성-표) "준비 중" 열(자료표 확인 전)
  - 단일 BLE SoC로 보임(별도 BLE 모듈이 안 보임). 확정은 기판 사진 확인 뒤
  - 블루투스 패치 안테나가 칩 핀 하나에 연결됨(위치는 3절). 핀 번호는 자료표로 확인 필요
- 구성: 2행 × 3열 = 6키, 무선. **별도 USB 동글**이 있음(동글 연결 방식·일반 블루투스 모드 유무는 확인 필요). 노브: 확인 필요. LED: L3~L8 6개 + L1·L2 (4절). 배터리: 확인 필요
- 스위치 SW1: 전원 스위치로 보임(켜면 LED 6개가 잠깐 켜짐, 자세한 동작은 확인 필요)
- 개발 보드 UID: 확인 필요
- 확인 근거: 사용자 관찰 (2026-11-13). 기판 사진·자료표 확인 전

### 식별 체크리스트

> ⚠️ 같은 제품이 여러 대면 **기준 한 대는 손대지 않고 보존**. 읽기 보호 해제 = **공장 펌웨어 영구 삭제**(되돌릴 수 없음). 블루투스 보드는 공장 펌웨어에 BLE 스택·페어링 정보가 있어 되살리기 더 어려움. 보호 상태 확인까지만 하고 다운로드는 하지 않음

#### 연결 방식 확인

> ⚠️ 동글이 하나뿐이면 망가뜨렸을 때 무선으로 쓸 수 없음 → **동글은 맨 마지막에** 건드림(분해·펌웨어 확인은 키보드를 다 본 뒤)

| # | 확인할 것 | 결과 |
|---|---|---|
| C1 | **동글만** PC에 꽂음: 장치 관리자의 VID/PID, 장치 종류(HID 키보드인지), 인터페이스 개수 | 확인 필요 |
| C2 | **키보드를 USB 선으로** 꽂음: 충전만 되는지, 유선 키보드로도 동작하는지, VID/PID | 확인 필요 |
| C3 | 동글 없이 PC·폰의 **블루투스 목록에 보이는지** (일반 블루투스 모드 유무) | 확인 필요 |
| C4 | 키보드·동글 **페어링 방법**: 처음부터 짝지어져 나오는지, 페어링 버튼·키 조합, 다른 동글과 짝지을 수 있는지 | 확인 필요 |
| C5 | 모드 전환 스위치·키 (2.4G / BT / 유선) | 확인 필요 |
| C6 | 동글 분해 가능 여부와 칩 표기 (동글 펌웨어도 바꿔야 할 수 있음) | 확인 필요 |

## 2. 버튼 배치와 매핑

- 2행 × 3열. 번호는 왼쪽 위부터 행 순서(1~3 윗줄, 4~6 아랫줄)로 붙일 예정
- 키 핀, 슬롯, 진입 키: 확인 필요

## 3. 칩 핀맵

- 칩 CH573F. 핀 번호·이름: 확인 필요(자료표 확인 뒤)
- 블루투스 패치 안테나 연결 핀 (사용자 관찰, 핀 번호 확인 전): 칩 윗면에서 1번 핀 표시 모서리를 **오른쪽 위**에 두었을 때, 오른쪽 아래 모서리 쪽 **아래 변의 가장 오른쪽 핀**
  - 그림·핀 번호는 자료표의 핀 배치와 맞춰 본 뒤 적음

## 4. LED

- 방식·극성·핀: 확인 필요
- 기판 표기 L3~L8 6개 + L1·L2 (사용자 관찰, 2026-11-13). 색은 SW1을 켰을 때 잠깐 켜지는 것으로 봄

| LED | 색 | 비고 |
|---|---|---|
| L1, L2 | 확인 필요 | L3~L8과 따로 있음, 용도 확인 필요 |
| L3 | 흰색 | |
| L4 | 초록 | |
| L5 | 확인 필요 | 안 켜짐 |
| L6 / L7 / L8 | 파랑 | |

- L5가 안 켜진 것과 "6개가 잠깐 켜짐"이 맞지 않음 → 다시 확인 필요
- LED와 키의 대응(키마다 LED인지, 상태 표시용인지): 확인 필요

## 5. 부팅·장입

- ROM 부트로더 진입 방법, USB 데이터 가능 여부, 장입 도구: 확인 필요
- 동글 방식(2.4G 전용 프로토콜)이면 키보드만 바꿔서는 무선 입력이 안 될 수 있음 → 동글 펌웨어도 대상인지 연결 방식 확인 뒤 정함
- USB 포트가 충전 전용이면 장입·설정 방법부터 따로 정함 ([NEW_BOARD.md 9-2](../NEW_BOARD.md#9-2-블루투스-보드-주의))

## 6. 본 펌웨어에서의 동작

- 해당 없음 (보드 파일·칩 HAL·BLE 전송 없음, 식별 후)
- 설정 통신은 지금 USB Vendor HID만 있음([PROTOCOL.md](../PROTOCOL.md)). 블루투스 입력·설정 방식은 식별 후 정함
