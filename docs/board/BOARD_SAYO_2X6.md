# SAYO_2X6 보드 (12키, 식별 전)

- 요약 표: [BOARDS.md](../BOARDS.md#준비-중-보드). 같은 계열: [SAYO_3X3](BOARD_SAYO_3X3V_RGB.md), [SAYO_2X4](BOARD_SAYO_2X4V_RGB.md). 문서 양식: [_TEMPLATE.md](_TEMPLATE.md)
- **상태: 식별 전**. 이름 `SAYO_2X6`은 임시(식별 뒤 바꿀 수 있음). 파일 위치: [NEW_BOARD.md 9절](../NEW_BOARD.md#9-식별-전-보드)
- 문서 파일 이름은 기판 표기를 모르는 동안 `BOARD_SAYO_2X6.md`. 식별 뒤 `BOARD_SAYO_<기판 표기>.md`로 바꿀 예정

## 1. 개요

- 제품: SayoDevice 계열 12키 매크로 키패드 (정확한 모델명 확인 필요)
- 칩: 확인 필요. 같은 계열 8키·9키가 CH32V203C8U6이라 같을 수 있음(짐작만, [NEW_BOARD 1절](../NEW_BOARD.md#1-식별): 겉모습으로 칩을 짐작하지 않음). 식별되면 [CHIPS.md](../CHIPS.md#칩-특성-표) "준비 중" 열에 특성 기록
- 구성: 2행 × 6열 = 12키. 노브: 확인 필요. LED: 확인 필요
- 개발 보드 UID: 확인 필요
- 확인 근거: 없음 (식별 전)

> ⚠️ 같은 제품이 여러 대면 **기준 한 대는 손대지 않고 보존**. 읽기 보호 해제 = **공장 펌웨어 영구 삭제**(되돌릴 수 없음). 보호 상태 확인까지만 하고 다운로드는 하지 않음

## 2. 버튼 배치와 매핑

- 2행 × 6열. 번호는 다른 보드처럼 왼쪽 위부터 행 순서(1~6 윗줄, 7~12 아랫줄)로 붙일 예정
- 키 핀, 슬롯, 진입 키: 확인 필요 (시험 펌웨어로 확인 뒤 그림·생성 구역 추가)

## 3. 칩 핀맵

- 확인 필요 (칩 식별 뒤)

## 4. LED

- 방식·극성·핀: 확인 필요

## 5. 부팅·장입

- ROM 부트로더 진입 방법, 자체 부트로더 필요 여부: 확인 필요
- CH32V203이면 8키·9키와 같은 방식(BOOT 브리지 + `-Full`, 이후 진입 키)일 가능성. 확인 전에는 장입하지 않음

## 6. 본 펌웨어에서의 동작

- 해당 없음 (보드 파일 없음, 식별 후)
