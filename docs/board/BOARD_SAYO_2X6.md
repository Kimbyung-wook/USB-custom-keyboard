# SAYO_2X6 (12키)

- 요약 표: [BOARDS.md](../BOARDS.md). 같은 계열: [SAYO_3X3](BOARD_SAYO_3X3V_RGB.md), [SAYO_2X4](BOARD_SAYO_2X4V_RGB.md). 문서 양식: [_TEMPLATE.md](_TEMPLATE.md)
- **상태: 핀 확인 완료, 본 펌웨어 확인 중**. 확인한 것: 칩, 키·LED 핀, 자체 부트로더 설치, 본 펌웨어의 꽂을 때 LED 점검, 부트로더 진입 보라 LED. 확인 전: 본 펌웨어 키 입력, GUI 설정 (7절)
- 이름 `SAYO_2X6`은 임시(기판 표기를 알면 바꿀 수 있음). 준비 범위와 파일 위치: [NEW_BOARD.md 9절](../NEW_BOARD.md#9-식별-전-보드)
- 문서 파일 이름은 기판 표기를 모르는 동안 `BOARD_SAYO_2X6.md`. 기판 표기를 알면 `BOARD_SAYO_<기판 표기>.md`로 바꿀 예정

## 1. 개요

- 제품: SayoDevice 계열 12키 매크로 키패드 (정확한 모델명 확인 필요)
- 보드 ID(펌웨어·GUI·`-Board`): `SAYO_2X6` (8자, 임시). 기판 표기: 확인 필요
- 칩: **CH32V203C8U6** (칩 표기 사용자 확인, `wchisp info` 칩 ID 0x3019, 2026-11-13). 8키·9키와 같은 칩. 특성: [CHIPS.md](../CHIPS.md#칩-특성-표)
- 구성: 2×6 키, **노브 없음**, 키마다 RGB LED 1개(색별 음극 + 키별 양극, 4절)
- 개발 보드 UID: `CD-AB-6B-22-66-BD-9E-8B` (`wchisp info`, 2026-11-13). 공장 펌웨어(USB `8089:000B`)는 보호 해제로 지워짐
- 확인 근거: [test_ch32v203](../../tests/hw/ch32v203/test_ch32v203/README.md#sayo_2x6-12키) KEYS·FIND·ANODE 모드, 본 펌웨어 꽂을 때 LED 점검 (2026-11-13)

- 표는 `tools/gen_docs.py`가 보드 파일에서 만듦
- 슬롯 = 키 번호 − 1. 칩 핀 번호는 3절
- 음극 묶음: 1 = 키 1·2·3·7, 2 = 키 9·10·11, 3 = 키 4·5·6·12. 키 8의 묶음은 미확인(4절)
- 특수 핀: PA14 = SWCLK(키 4), PA15 = JTDI(키 2), PA13 = SWDIO(묶음 1 파랑), PB3·PB4 = JTAG 핀(키 3·4 LED 양극) → SWJ를 끄고 사용(HAL이 처리, 9키와 같음)
- 진입 키 7은 왼쪽 아래(PA7, 슬롯 6, `BOARD_BOOT_KEY 6`). 키 7 진입 실물 확인(2026-11-13)
- 번호: 1~6 윗줄, 7~12 아랫줄 (왼쪽부터)
- 키 12개 모두 **핀 하나 + GND**(매트릭스 아님), 누르면 낮음, 내부 풀업
- PC13~PC15는 저속 핀(출력 약함). 키 입력으로는 문제없음
- PB2(BOOT1)는 시작부터 낮음(`STUCK PB02`, 기판 풀다운으로 보임) → 키 아님, 키 8 LED 양극

## 4. LED

- 방식: 8키·9키와 같음. **색별 음극**(낮추면 켜짐, 키 묶음이 공유) + **키별 양극**(높이면 켜짐, 핀은 2절 표). WS2812 아님
- 구동 방식·밝기는 9키와 같음(색마다 차례로, 키별 양극으로 밝기, [BOARD_SAYO_3X3V_RGB.md 4절](BOARD_SAYO_3X3V_RGB.md#4-led))
- 그림(`leds_sayo_2x6.svg`): 아직 없음

| 묶음 | 키 | 빨강 | 초록 | 파랑 |
|---|---|---|---|---|
| 묶음 1 | 1·2·3·7 | PA11 | PA12 | PA13 |
| 묶음 2 | 9·10·11 | PA8 | PA9 | PA10 |
| 묶음 3 | 4·5·6·12 | PA0 | PA1 | PA2 |

- 음극 핀은 9키와 같고 묶음만 다름
- 시험 펌웨어로 못 본 핀 3개는 본 펌웨어 꽂을 때 LED 점검에서 **12키 모두 빨강·초록·파랑이 켜져 확인**(추정 아님, 2026-11-13)
  - PA11·PA12: 시험 펌웨어가 건드리지 않는 핀(USBD) → 묶음 1의 빨강·초록
  - PB2: 시험에서 `STUCK`이라 제외 → 키 8 양극
- 키 8의 음극 묶음: 미확인. 본 펌웨어는 색마다 모든 묶음을 함께 구동하므로 몰라도 동작
- 꽂을 때 LED 점검: 6절

**이력**

- 2026-11-13: 시험 펌웨어 FIND·ANODE로 음극·양극 확인, PA11·PA12·PB2는 본 펌웨어 LED 점검으로 확인

## 5. 부팅·장입

- 평소 업데이트: 자체 HID 부트로더. **키 7을 누른 채 꽂기** 또는 GUI [업데이트 모드로 전환] → GUI 업데이트 창 (설정 유지)
- 처음 설치·복구: **BOOT 브리지**를 이은 채 꽂고 `tools\flash.ps1 -Board sayo_2x6 -Full` → wchisp로 부트로더만 쓴 뒤 브리지 떼고 **키 7**을 누른 채 다시 꽂으면 앱을 HID로 씀. 절차: [MANUAL 8장](../MANUAL.md#처음-설치-공장-펌웨어)
- 절차·플래시 배치: [BOOTLOADER_CH32V203.md](../BOOTLOADER_CH32V203.md)
- ROM 부트로더: BOOT 브리지 → `4348:55E0`. Windows는 WinUSB 드라이버가 붙은 포트에서만 wchisp 동작
- 지금 들어 있는 자체 부트로더: LED 핀이 들어간 빌드(`bootloader-SAYO_2X6.bin`, 4,472 B)를 wchisp로 써서 바꿈(검증 OK, 2026-11-13). 키 7 진입 시 전체 보라 LED 실물 확인(2026-11-13)
- 시험 펌웨어도 브리지 없이 올릴 수 있음: `APP=1` 빌드를 키 7 + `hidboot flash --force` ([test_ch32v203 README](../../tests/hw/ch32v203/test_ch32v203/README.md#부트로더-뒤에-올리기-app1-브리지-없이))
- ⚠️ 공장 펌웨어는 읽기 보호(WRP도 일부 걸림). 보호 해제 때 지워짐(되돌릴 수 없음)

**이력**

- 2026-11-13: 보호 해제 뒤 자체 부트로더(LED 핀 없는 빌드, 4,044 B) + 앱 자리 시험 펌웨어를 `mkfull.py`로 합쳐 wchisp로 설치, 키 7 진입(`hidboot info`: 부트로더 1.0, SAYO_2X6) 확인
- 2026-11-13: 부트로더를 LED 핀이 들어간 빌드(4,472 B)로 바꿈(전에는 진입해도 LED 표시 없음)

## 6. 본 펌웨어에서의 동작

- 보드 파일: `firmware/macro_keyboard/src/boards/sayo_2x6.h`
- 빌드: `tools\build_fw.ps1 -Board sayo_2x6` → 앱 `macro_keyboard-SAYO_2X6.bin`, 전체 이미지 `full-SAYO_2X6.bin`(`flash.ps1`은 안 씀)
- 슬롯 12개: 키 1~12. 문자열 합계 최대: 확인 필요
- 잠금·LED·저장: 9키와 같음 ([BOARD_SAYO_3X3V_RGB.md 6절](BOARD_SAYO_3X3V_RGB.md#6-본-펌웨어에서의-동작)). 누르는 동안 누른 키만 초록, 나머지는 꺼짐
- 꽂을 때 LED 점검 (`BOARD_LED_SELF_TEST`, `led.c`의 `wheelRing()`): 약 6.3초, 그 뒤 평소 동작
  - **빛 2개**가 둘레에서 마주 보며(6칸 떨어져) 시계방향으로 흐름. 둘레 순서 1→6→12→7, 즉 1, 2, 3, 4, 5, 6, 12, 11, 10, 9, 8, 7 (`BOARD_LED_RING`), 한 바퀴 1초
  - 빛 수: `BOARD_LED_RING_CHASE 2`. 둘레가 길어 2개로 함(다른 보드는 1개)
  - 빛마다 이웃한 두 칸 교차 페이드(현재 칸이 어두워지는 동안 다음 칸이 밝아짐), 나머지 칸은 꺼짐
  - 빛의 색: 색 바퀴(빨강→노랑→초록→청록→파랑→보라→빨강)를 3초 주기로 2번. 끝나면 0.3초 꺼짐
  - 12키 모두 둘레라 계속 켜진 키 없음
  - 빌드 옵션: `BOARD_LED_RING_CHASE 0`이면 무지개 회전(모든 칸이 켜진 채 색이 시계방향으로 이동)

**이력**

- 2026-11-13: 보드 파일 추가, LED 점검 빛 2개
