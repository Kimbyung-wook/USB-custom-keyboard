# 칩 특성

- 이 프로젝트가 쓰는 칩의 특성을 한 곳에 모은 표. 보드 문서 1절(개요)은 칩 이름과 이 표 링크만 둠
- 보드별 값(키·LED 핀, 진입 키)은 [BOARDS.md](BOARDS.md)와 보드 문서

## 칩 특성 표

- 값의 출처 두 가지
  - **자료표 값(손으로 씀)**: 칩 자체의 사양. 근거는 자료표 이름·버전·표 (PDF는 저장소 밖 `MacroKeyboard/reference/`)
  - **코드 값**: 우리 펌웨어·GUI가 쓰는 배치·한도(`gui/core/chips.py`, `firmware/macro_keyboard/src/hal/ch32v203/boot_layout.h`, `firmware/macro_keyboard/src/config.h`). 나중에 생성 구역(`chips`)으로 옮길 수 있음. 아래 표에서는 **(코드)**로 표시
- "준비 중" 열: 식별 전 보드(BT_2X3)의 칩. 지금 칩 표기 **CH573F**(사용자 관찰, 2026-11-13). 자료표가 아직 없어 값은 모두 **추정**(기억에 의한 값, 자료표 확인 필요). 자료표로 확인하면 열 이름을 칩 이름으로 바꾸고 "추정"을 지움. SAYO_2X6은 CH32V203C8U6으로 확인(2026-11-13) → CH32V203C8U6 열

| 항목 | CH552G | CH32V203C8U6 | 준비 중: CH573F (BT_2X3, 추정) |
|---|---|---|---|
| 코어 | E8051 (MCS51 호환) | QingKe V4B (32비트 RISC-V) | 32비트 RISC-V (QingKe V3 계열, 추정) |
| 최대 클럭 / 우리 설정 | 24 MHz / 24 MHz 내부 클럭 | 144 MHz / 48 MHz 내부 HSI(`SYSCLK_FREQ_48MHz_HSI`, USBFS 48 MHz용) | 확인 필요 |
| 코드 Flash 전체 | 16 KB | 무대기 영역 64 KB + 비무대기 영역(224 KB − 64 KB). 우리 배치는 앞 64 KB만 씀 | 확인 필요 |
| 부트로더 | ROM 부트로더 2 KB (16 KB 중 BootLoader 영역, 우리 장치는 2.5.0) | ROM 부트로더 28 KB(시스템 영역, BOOT0=1로 진입) + **자체 HID 부트로더 8 KB**(0x08000000~, **코드**) | 확인 필요 |
| 앱에 쓸 수 있는 양 | 14,336 B (**코드**, 16 KB − 2 KB) | 52,992 B (0x08002000~0x0800EEFF, **코드**). 그 뒤 앱 정보 256 B(0x0800EF00) | 확인 필요 |
| RAM | iRAM 256 B + xRAM 1 KB | SRAM 20 KB | 확인 필요 |
| 설정 저장 | DataFlash 128 B (바이트 단위 재기록) | 플래시 끝 4,096 B (0x0800F000~, 업데이트해도 유지, **코드**) | 확인 필요 |
| 문자열 합계 최대 | 102자 | 4,070~4,072자 (키 수에 따라, [BOARDS.md](BOARDS.md#구성)) | – |
| 패키지·핀 수 | SOP16, 16핀 | QFN48, 48핀 (+ 바닥 패드 VSS) | QFN 계열(접미 F, 추정). 핀 수 확인 필요 |
| GPIO 수 | 칩 전체 최대 17(TSSOP20 기준). SOP16에 나온 GPIO는 12개 + RST(USB D+/D− 포함, [MK6K1N 3절](board/BOARD_MK6K1N.md#3-칩-핀맵)) | 37 | 확인 필요 |
| USB | 장치 전용 풀스피드 1개 (P3.6/P3.7). D+ 1.5 kΩ 풀업 칩 안에 있음(`bUC_DEV_PU_EN`) | USBD(PA11/PA12, 장치 전용) + USBFS(PB6/PB7, 호스트/장치). 우리 펌웨어는 USBFS, 풀업은 칩 안(`USBFS_UC_DEV_PU_EN`) | 풀스피드 USB 있음(추정). 이 기판에서 USB 데이터 선이 이어졌는지는 확인 필요 |
| 무선 | 없음 | 없음 | BLE 내장(추정). 이 기판은 패치 안테나([BOARD_BT_2X3 3절](board/BOARD_BT_2X3.md#3-칩-핀맵)) |
| 공급 전압 | VCC 5 V 또는 3.3 V(2.8 V까지). 칩 안 5 V → 3.3 V 레귤레이터(V33 핀). 플래시 쓰기는 5 V 필요 | VDD 2.4~3.6 V (정격 3.3 V) | 확인 필요 |
| 고유 ID | 있음 (HELLO 32~35) | 96비트 (HELLO는 앞부분) | 확인 필요 |
| 칩 ID (HELLO 18, **코드**) | `0x52` | `0x19` | – |
| 근거 | 자료표 CH552 V1F, 1장 개요 표·2장 특성·7장 전원 | 자료표 CH32V203 V2.6, 특성·표 2-1(제품 자원)·표 3-1-1(핀 정의) | – |

## 우리 펌웨어의 사용량

- 근거: [firmware/macro_keyboard/README.md](../firmware/macro_keyboard/README.md#크기) "크기" (빌드 시각에 따라 ±4 B)

| 칩 | 코드(1.7.0) | 한도 대비 | RAM |
|---|---|---|---|
| CH552G | 9,629 B (LED 1개 보드), 10,006 B (키마다 LED 보드) | 67~70% / 14,336 B | 1.6.0 기준 전역 변수 약 360 B + 스택 약 120 B (1.7.0 값은 확인 필요) |
| CH32V203C8U6 | 앱 12,292~12,304 B | 약 23% / 52,992 B | 확인 필요 |

**이력**

- 2026-11-08: 처음 만듦 (자료표 CH552 V1F, CH32V203 V2.6)
- 2026-11-13: "준비 중" 열에 CH573F(BT_2X3) 추정 값. 자료표 확인 전
