# 3X3V_RGB 보드 (9키)

- 제품: SayoDevice 계열 9키 매크로 키패드 (같은 계열 8키 = Keyb T8B7, [2X4V_RGB](PORT_CH32V203.md))
- 칩: **CH32V203C8U6** (RISC-V QingKe V4, 플래시 64 KB, RAM 20 KB, USB 풀스피드)
- 구성: 3×3 키, **노브 없음**, 키마다 3색 한 칩 RGB LED
- 확인 근거: [test_ch32v203](../tests/hw/ch32v203/test_ch32v203/README.md) 시험(2026-11-05), 분해 확인(사용자)

## 키 배치

(그림: 사용자가 추가)

| 키 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|---|
| 핀 | PB15 | PA14 | PA4 | PB10 | PA15 | PA3 | PB2 | PB11 | PB1 |

- 번호: 왼쪽 위부터 행 순서 (1~3 윗줄)
- 누르면 낮음, 내부 풀업
- PA14·PA15는 SWD/JTAG 핀 → SWJ를 끄고 사용 (디버거 연결 불가)
- PB2(키 7)는 BOOT1과 같은 핀

## LED

(그림: 사용자가 추가)

| 줄 | 키 | 빨강 | 초록 | 파랑 |
|---|---|---|---|---|
| 1 | 1·2·3 | PA11 ⚠️ | PA12 ⚠️ | PA13 |
| 2 | 4·5·6 | PA8 | PA9 | PA10 |
| 3 | 7·8·9 | PA0 | PA1 | PA2 |

- WS2812가 아님. 줄마다 색별 핀 1개를 키 3개가 공유, **낮추면 켜짐**
- 초록이 훨씬 밝음 → 펌웨어에서 색별 밝기 보정
- ⚠️ PA11/PA12는 USB D−/D+ → 펌웨어는 1줄 빨강·초록을 쓰지 않음(파랑만)
- 키별 제어 가능 여부: 미확인 (애노드 배선을 모름, 아래 "참고 키보드로 확인할 것")

## 부팅·장입

- 부트로더 진입: **BOOT 브리지**(BOOT1 실크 아래 패드 2개)를 이은 채 USB 연결
- 소프트웨어 진입 불가 (부트로더로 점프하면 `csrw 0xbc0`에서 예외)
- 장입: `wchisp flash <bin>` → 브리지 제거 → USB 재연결
- ⚠️ 제조사 펌웨어는 읽기 보호. 보호 해제 때 지워짐(되돌릴 수 없음)

## 본 펌웨어에서의 동작

- 빌드·상태: [PORT_CH32V203.md](PORT_CH32V203.md)
- 잠금(패턴 암호) 없음 (노브가 없음)
- LED: 줄 단위로 같은 색 (상태 표시)
- GUI 업데이트 창으로는 장입 불가 → wchisp 사용

## 참고 키보드로 확인할 것 (원본 펌웨어 그대로)

> 원본 펌웨어를 지우지 않음. 보호 해제(unprotect) 금지

1. SayoDevice 웹 도구에서 키마다 다른 색 지정
   - 같은 줄 3키가 서로 다른 색 → 키별 제어 회로 있음 → LED 주변 핀 측정
   - 항상 같은 색 → 줄 단위가 하드웨어 한계
2. 1줄이 빨강·초록으로 켜지는지 (PA11/PA12와 USB 공존 여부)
3. USB 디스크립터: VID/PID, 인터페이스 수, 리포트 형식
4. 웹 도구의 WebHID 통신 관찰 (설정 방식 참고)
5. PB6 전압 (동작 중, 키 누를 때)
6. BOOT 브리지 + `wchisp probe`로 읽기 보호 상태만 확인 → 보호가 없으면 플래시 덤프·분석
